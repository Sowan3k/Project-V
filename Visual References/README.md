# Visual References

UI/UX mockups for Vindeshi Express, produced during product design.

**The authoritative documentation for these images is [CLAUDE.md](../CLAUDE.md) §8.**
Read that section before using any of them. It carries the index, per-reference notes, design
principles, known mockup exceptions and the intended screen flow.

This file exists only for human convenience when browsing the folder. **Do not treat it as
implementation guidance.**

## Three things to know before opening any image

1. **Mockups lose.** If an image conflicts with `REQUIREMENTS.md` or `CLAUDE.md`, the higher
   document wins. These images define design *intent*, not requirements.
2. **All sample data is illustrative.** Universities, IELTS/APS/visa requirements, fees,
   durations, follower counts, freshness and confidence percentages, usernames and statistics
   are placeholders. **None of it is seed data or factual.**
3. **Some mockup elements are explicitly out of scope** — "Share Progress", "Verified Route",
   community-approval gating of updates, alert subscriptions, a safety leaderboard. See
   CLAUDE.md §8.6 for the full list and why.
